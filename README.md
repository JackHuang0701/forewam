# ForeWAM Project Page

Static project page for **Foresight Without Seeing: Latent Futures for World Action Models**.

This repository hosts the paper website only. The ForeWAM model and training code are not included and are marked **Coming soon** on the page.

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deployment

The site is intended for GitHub Pages at:

`https://jackhuang0701.github.io/forewam/`

All asset references are relative so the page works from the project subpath.
